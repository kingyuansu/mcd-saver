# 麦门省钱助手 McD Saver

**基于麦当劳 MCP 的点餐辅助与价格核验工具**

## 一、项目简介

麦门省钱助手是一款基于麦当劳 MCP 工具链的轻量化点餐辅助工具，旨在帮助用户查询附近门店、浏览可用餐品、核验商品价格，并为后续的套餐选择与消费决策提供辅助。

项目尝试将真实 MCP 工具调用与清晰的业务规则结合，减少用户在门店、餐品和价格信息之间反复切换的成本。

## 二、核心功能

- **附近门店查询**：通过 MCP 查询指定位置附近的门店。
- **餐品信息查询**：获取指定门店返回的餐品及价格信息。
- **价格核验**：调用价格计算工具核验商品金额，并统一元与分的单位。
- **营养信息辅助**：查询可用的餐品营养数据，在名称能够可靠匹配时提供参考。
- **优惠信息查询**：查询接口实际返回的优惠信息，不将未验证的优惠宣传为已生效折扣。
- **消费决策辅助**：基于已核验的信息，为用户提供点餐参考。

## 三、真实工具链验证

项目已开展真实 MCP 工具调用验证，覆盖门店查询、餐品查询与价格计算等核心环节。

验证过程中，曾查询上海人民广场附近门店，并选取门店 `1450713` 进行餐品及价格核验。餐品 `9900005456` 的查询价格为 33.5 元，价格计算工具返回 3350 分，二者一致。

以上是特定测试场景的验证结果，不代表所有门店、餐品、时段及优惠均已验证。

## 四、项目边界与安全设计

- 以实际 MCP 返回结果为依据，不伪造门店、餐品、价格或优惠。
- 不将未成功核验的优惠描述为已经生效。
- 对无法可靠匹配的营养信息明确标注限制。
- 示例配置只使用 Token 占位符，不在公开仓库中保存真实凭证。
- 不自动执行下单、取消订单等写操作。

## 五、技术方案

项目围绕麦当劳 MCP 服务组织业务流程，重点验证门店查询、餐品查询和价格计算之间的数据衔接，并通过规则约束提高结果的可解释性。

MCP 服务地址：`https://mcp.mcd.cn`

## 六、目标用户

- 希望根据预算挑选麦当劳餐品的消费者。
- 希望核验餐品查询价格与计价结果是否一致的用户。
- 希望了解 MCP 工具调用、数据核验和本地组合算法的开发者。

## 七、安装与运行

### 环境要求

- Python 3.10 或更高版本。
- 运行自动化测试需要 Python 标准库，无须额外安装第三方 Python 依赖。

### 运行预算组合计算器

下载或克隆本项目后，在项目根目录执行：

```bash
python scripts/combo_optimizer.py
```

程序将使用内置的演示餐品数据，计算不超过指定预算的餐品组合。演示数据不代表实时菜单或当前售价。

### 运行自动化测试

在项目根目录执行：

```bash
python -m unittest discover -s tests -v
```

也可以在 GitHub 仓库的 Actions 页面查看自动化测试运行结果。

### 使用麦当劳 MCP

1. 按照麦当劳官方 MCP 接入说明申请 Token。
2. 在支持 Streamable HTTP 的 MCP 客户端中配置服务地址及认证信息。
3. 查询目标门店、餐品及价格。
4. 根据实际查询结果核验金额，并在需要时将餐品及价格输入本地组合计算器。

具体客户端配置方法以所使用客户端的说明为准。不要将真实 Token 提交到公开仓库。

## 八、使用示例

### 示例一：预算组合计算

运行本地组合计算器，程序会使用内置演示数据，输出不超过 40 元的餐品组合及剩余预算。

### 示例二：真实餐品价格核验

在已连接麦当劳 MCP 的客户端中，查询目标门店餐品，并使用价格计算工具核验金额。

历史测试中，餐品 `9900005456` 的查询价格为 33.5 元，计价工具返回 3350 分，换算后为 33.50 元。该案例仅为历史验证记录，不代表当前所有门店的实时售价。

本地组合计算器与 MCP 查询是两个不同环节。当前版本不应被描述为已经实现全自动的实时菜单获取、优惠抵扣或下单流程。

本项目为麦当劳程序员节创意开发大赛参赛作品，由参赛者独立开发，非麦当劳官方产品。实际餐品、价格、营养及供应状态以麦当劳官方渠道的实时结果为准。

项目输出仅供参考，不构成医疗、营养或其他专业建议。
