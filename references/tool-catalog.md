# 麦门省钱助手：MCP 工具目录

## 1. 说明

本文件记录麦门省钱助手使用或评估过的麦当劳 MCP 工具，以及现阶段的验证情况。

MCP 服务地址：`https://mcp.mcd.cn`

传输方式：Streamable HTTP。

认证方式：通过 `Authorization: Bearer <TOKEN>` 请求头提供认证信息。

实际工具参数和返回结构以麦当劳 MCP 服务当前提供的定义为准。

## 3. 典型验证案例

### 案例一：查询门店

查询上海人民广场附近门店，返回结果中选择门店 `1450713`，记录显示其距离约为 144 米。

该结果仅用于说明测试时的真实调用情况，不代表该门店当前距离或营业状态。

### 案例二：查询餐品

对测试门店调用餐品查询工具，获取餐品 `9900005456` 的查询价格为 33.5 元。

### 案例三：核验价格

对上述餐品调用价格计算工具，返回价格为 3350 分，换算后为 33.50 元。

本次测试中，餐品查询价格与计价结果一致。

### 案例四：查询优惠

测试时，门店优惠查询返回空数组，个人优惠券查询没有返回可用优惠券。

因此，本次测试不能证明优惠已经成功抵扣，也不能据此推断其他门店或时间没有优惠。

## 4. 数据处理规则

### 金额单位

- `query-meals` 返回的 `currentPrice` 按接口实际定义以元处理。
- `calculate-price` 返回的 `price` 等计价金额字段按接口实际定义以分处理时，展示前除以 100。
- 不同工具字段必须分别核对单位，不能将所有金额字段一律换算。

### 营养信息

营养数据只有在餐品名称和规格能够可靠匹配时才使用。

由于营养数据与菜单商品编码不能直接完整关联，无法确认匹配关系的餐品不应强行关联。套餐营养值也不能简单等同于其中某个单品的营养值。

### 优惠信息

查询到优惠信息，不代表优惠已经应用到订单。

只有价格计算结果能够证明优惠生效时，才可以向用户说明折扣已经计入价格。

## 5. 安全边界

- 不将真实 Token 或其他认证凭证提交至公开仓库。
- 不伪造工具调用结果。
- 不将本地组合计算结果描述为 MCP 服务返回结果。
- 当前项目以查询、价格核验和预算组合辅助为主。
- 未经进一步验证，不自动执行下单或取消订单等写操作。
